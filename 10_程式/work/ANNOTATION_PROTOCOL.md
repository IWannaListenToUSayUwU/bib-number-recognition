# 標註規範 v1（標準答案用）

## 素材
每段片段一個資料夾，內含 f_000.jpg … f_059.jpg。每張圖含 1～2 格畫面（每秒 2 格），左上角黃字為該格的全域時間（秒）。
畫面已裁切並放大，只保留號碼牌可能看得清的區域。

## 任務
列出片段中每一位「身上有號碼牌的人」（跑者），每人只列一次。跨格依外觀（衣服、帽子、體型）判斷是否為同一人。

對每位跑者記錄：
- `bib`：號碼。看得清的數字照寫；某一位看不清就寫 `?`（例如 `14?4`）；位數都無法確定就寫 `?`。
- `status`：`sure`（每一位都確定）、`partial`（含 `?`）、`unreadable`（看得到號碼牌但完全讀不出）。
- `t_first` / `t_last`：此人號碼牌在素材中出現的第一與最後時間（秒，取圖上的時間）。
- `t_best`：號碼牌最清楚的那格時間。
- `note`：可選，外觀描述（例如「紅衣黑帽」），方便日後對照。

## 規則
1. **寧可寫 `?`，不可猜**。只要有一絲懷疑就標 `?`，這比寫錯好。
2. 不要列入非號碼牌的數字：車牌、計時器、看板、衣服上的印字、號碼牌上的固定賽事字樣（例如 "BBB 10K"）。
3. 背景遠處的小號碼牌也要列；看不清就標 `unreadable` 或 `partial`。
4. 同一號碼若出現在兩個明顯不同的人身上，分開列並在 note 說明。
5. 另外估計 `no_bib_runners`：看起來在跑步/完賽、但整段都看不到號碼牌的人數（號碼牌被遮住、背對等）。觀眾、工作人員不算。
6. 只看自己被指派的資料夾，只寫自己被指派的輸出檔，不要讀取其他標註檔。

## 輸出格式（JSON）
```json
{"clip": "v3_1440", "annotator": "A",
 "runners": [{"bib": "85", "status": "sure", "t_first": 1458.5, "t_best": 1460.0, "t_last": 1461.0, "note": "紅衣黑帽"}],
 "no_bib_runners": 3,
 "comments": "整體觀察，可選"}
```

## 標準答案的合併（由主執行者／裁定者處理，標註者不需理會）
- A、B 皆 sure 且一致 → 直接採用。
- 不一致或一方 partial → 由第三方回看原格裁定，可裁定為 sure / partial / unreadable。
- 主要指標的分母 = 裁定後 `sure` 的號碼；`partial`、`unreadable` 另列為「人眼無法完整判定」。
