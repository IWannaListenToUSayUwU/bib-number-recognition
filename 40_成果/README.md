# 40_成果：成果總覽（2026-11-23 更新）

馬拉松號碼布辨識＋過線計時。版本演進見 [`../版本紀錄.md`](../版本紀錄.md)；做實驗的規則見 `../規格.md`。

## 目前能做到什麼
- 從比賽影片中找出每個跑者、讀出號碼布，並算出他**通過計時線的時間**（畫面上自訂的虛擬線）。
- 有入鏡的比賽時鐘時，過線時間可以換成**槍聲時間**（終點線機位：和官方成績的差有 90% 落在一個寬 1 秒的視窗內——官方只到整秒，代表系統誤差多半 < 0.3 秒）。

| 機位（2022 臺北馬） | 評分方式 | 結果 |
|---|---|---|
| 轉角機位 C、D 段 | 人工過線正確答案（score_v2：號碼和過線時間都對） | **0.754**（92/122，95% CI 0.67–0.82）；時間誤差中位數 0.06 秒 |
| 終點線機位（檢查集 3 段） | 官方完賽名單（號碼＋時間 ±2 秒的找到率） | v2.2 0.150 → **號碼規則（v3.0 候選）0.225**，錯誤輸出 25 → 3 |
| 轉角機位 A～D（只看出現的號碼） | 官方完賽名單獨立評估 | v2.2 每秒 16 格：精確度 0.86～0.94、召回 0.78～0.94；加號碼名單規則後精確度再升到約 0.95～0.98（召回不變） |

- 終點線機位讀號碼仍弱：影片過曝、號碼對比低，OCR 模型讀不到大部分號碼（R13 已確認不是裁切或前處理的問題）。
- 速度：60 秒片段約需 11～12 分鐘（OCR 在 CPU 上）；離即時還很遠，要 OCR 改用 GPU。
