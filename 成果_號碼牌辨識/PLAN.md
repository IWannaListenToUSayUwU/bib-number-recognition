# 馬拉松號碼牌辨識專題 — 實驗計畫（活文件）

## 目標
輸入終點線影片 → 輸出每位跑者的號碼牌號碼（含出現時間、信心值），並以可信的方式量出準確率。

| v2 | 20th Annual Millennium Mile | 17:59 | 720p 29.97fps | 拱門終點、人群極密、嚴重遮擋、畫面有台標 |

號碼牌在最接近鏡頭時約 40–60 px 寬。

## 運算環境（實測）
- 雲端容器：2 核 CPU、7GB RAM、無 GPU；可連 PyPI、GitHub releases；Hugging Face / PyTorch 官方源 / 百度 bcebos 不通。
- 使用者電腦的 Linux VM：2 核、3GB、無 GPU；有 ffmpeg；用於裁片、抽影格、存放成果。
- Windows 終端機：computer-use 對終端機只允許點擊、不允許打字 → 不採用。

## 評估設計（先定義，避免事後挑指標）
- **主要指標（系統層級，以跑者為單位）**：每個測試片段的標準答案 = 片段中「人眼可讀」的號碼集合。
  系統輸出號碼集合 → Precision / Recall / F1。人眼無法判定者另列，不計入分母。
- **次要指標（元件層級）**：號碼牌偵測（有無框到）、單張裁切 OCR 的完全正確率。
- **速度**：每秒影片的處理時間（CPU）。
- **資料切分**：dev 片段（調參用）與 test 片段（鎖定，最後只跑一次）。三支影片都要有 dev 和 test，且時段不重疊。
- 標準答案：主 agent 標註 + 獨立子 agent 盲標，不一致者再裁定。

## 候選方法（皆需實測）
- 偵測：YOLO11 person → 軀幹區域；或直接偵測文字區塊（RapidOCR/PP-OCR det、EasyOCR CRAFT）。
- 辨識：RapidOCR(PP-OCR rec)、EasyOCR、Tesseract、PARSeq。
- 後處理：數字過濾、長度規則、跨影格追蹤 + 投票、超解析/放大。
